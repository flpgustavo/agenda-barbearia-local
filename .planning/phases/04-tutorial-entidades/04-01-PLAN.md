Criar hook com gerenciamento de estado via localStorage:

- STATE: isActive (boolean), currentStepIndex (number), isCompleted (boolean)
- PERSISTENCE: Salvar em localStorage chave "agenda-tutorial-state"
- NAVEGAÇÃO: goToNext(), goToPrevious(), goToStep(index)
- CONTROLE: start(), skip(), complete()

Padrão de storage:
```typescript
const STORAGE_KEY = 'agenda-tutorial-state';

interface StoredState {
  isActive: boolean;
  currentStepIndex: number;
  isCompleted: boolean;
  lastUpdated: number;
}
```

Utilizar useState com initializer que carrega do localStorage:
```typescript
const [state, setState] = useState<StoredState>(() => {
  if (typeof window === 'undefined') return defaultState;
  const stored = localStorage.getItem(STORAGE_KEY);
  return stored ? JSON.parse(stored) : defaultState;
});
```

E persistência via useEffect:
```typescript
useEffect(() => {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(state));
}, [state]);
```
