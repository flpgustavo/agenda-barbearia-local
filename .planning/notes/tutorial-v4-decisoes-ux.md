## Decisões de UX

### Estilo
- **Direto e funcional** — sem enrolação, focado em mostrar como usar

### Fluxo
- Sequencial pelo menu, criando entidades em ordem
- Passo a passo: cliente → serviço → agendamento

### UI
- **Overlay** sobre a tela
- Destaque visual na área de ação + texto informativo instructing o que fazer

### Progressão
- Usuário clica "próximo" para avançar em cada passo
- Não avança automaticamente após criar entidade

### Término
- Mensagem de "parabéns, você completou"
- Botão para encerrar o tutorial
