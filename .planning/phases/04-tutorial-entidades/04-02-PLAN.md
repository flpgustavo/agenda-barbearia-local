Criar componente de indicador de progresso:

- Propriedades: currentStep (number), totalSteps (number)
- UI: Círculos conectados por linha
  - Passo atual: circulo preenchido com cor primária
  - Passos futuros: circulo outlines
  - Passos completos: circulo preenchido com checkmark
- Layout: Horizontal centered
- Estilo: tailwind (w-3 h-3 rounded-full, border-2, transition-colors)

```tsx
export function StepIndicator({ currentStep, totalSteps }: Props) {
  return (
    <div className="flex items-center gap-2">
      {Array.from({ length: totalSteps }).map((_, index) => (
        <div key={index} className="flex items-center">
          <div className={cn(
            "w-3 h-3 rounded-full border-2 transition-colors",
            index < currentStep ? "bg-primary border-primary" :
            index === currentStep ? "bg-primary/50 border-primary" :
            "bg-muted border-muted-foreground"
          )} />
          {index < totalSteps - 1 && (
            <div className={cn(
              "w-8 h-0.5 transition-colors",
              index < currentStep ? "bg-primary" : "bg-muted"
            )} />
          )}
        </div>
      ))}
    </div>
  );
}
```

   - Descrição: text-sm text-muted-foreground
   - Botões: Previous (ghost), Skip (outline), Next (default primary)

Posicionamento:
- 'top': card abaixo do highlight
- 'bottom': card acima do highlight  
- 'left': card à direita do highlight
- 'right': card à esquerda do highlight

Destaque visual (highlight):
```tsx
<div

    height: targetRect?.height + 16,
```
