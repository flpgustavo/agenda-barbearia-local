# Phase 4.1 — UI Design Contract

> Visual and interaction contract for TutorialOverlay component. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Tailwind CSS v4 |
| Preset | custom (no shadcn init — custom components on Radix UI) |
| Component library | Radix UI Dialog, Drawer |
| Icon library | Lucide React |
| Font | Quicksand (variable, via Next.js Google Fonts) |

---

## Spacing Scale

Declared values (Tailwind v4 default multiples):

| Token | Value | Usage |
|-------|-------|-------|
| 1 | 4px | Icon gaps, micro spacing |
| 2 | 8px | Compact element spacing |
| 3 | 12px | Between icon and label |
| 4 | 16px | Default element spacing |
| 5 | 20px | Dialog body padding |
| 6 | 24px | Section padding |
| 8 | 32px | Dialog max-width (sm), major gaps |
| 10 | 40px | Dialog footer height alignment |
| 12 | 48px | Large section breaks |
| 14 | 56px | Step indicator width |

Exceptions:
- **Step indicators (dots):** 12px × 12px (min touch target 44px achieved by wrapping in 44px button)
- **FAB (floating action button):** 56px × 56px (h-14 w-14 in Tailwind)

## Color

| Role | Light Value | Dark Value | Usage |
|------|-----------|-----------|---------|
| Dominant (60%) | #f0f4f8 | #101318 | Page background |
| Secondary (30%) | #dce4eb | #62738d | Overlay backdrop, step indicator inactive |
| Accent (10%) | #ff592c | #ff592c | Active step indicator, primary CTA, ring |
| Card | #ffffff | #2b333f | Dialog background |
| Destructive | #ef4444 | #7f1d1d | Destructive actions only |

**Accent (#ff592c) reserved for:**
1. Active step indicator dot (filled)
2. "Criar" CTA button (primary filled)
3. Focus ring (`--ring: #ff592c`)
4. Progress line between steps (filled portion)

**Accent NEVER used for:**
- Dialog close button
- Skip tutorial text link
- Inactive step indicators
- Footer secondary buttons

## TutorialOverlay Component Spec

### Layout

```
┌─────────────────────────────────────┐
│  [X]              Step 1/3          │  ← Header: close button, step counter
├─────────────────────────────────────┤
│                                     │
│         (1)  ──○──  (2)  ──○──  (3)│  ← Step indicators: circles + connecting lines
│                                     │
│  ┌───────────────────────────────┐     │
│  │  Step Title                 │     │  ← Step content card
│  │  Step description copy    │     │
│  │                           │     │
│  │  [Action CTA button]       │     │  ← Primary action
│  └───────────────────────────────┘     │
│                                     │
├─────────────────────────────────────┤
│  [Pular tutorial]     [Voltar] [Avançar]│  ← Footer: skip + navigation
└─────────────────────────────────────┘
```

### Visual States

**Step Indicator States:**
| State | Appearance |
|-------|------------|
| Active (current step) | Filled circle, accent color (#ff592c), scale-110 |
| Completed (past step) | Filled circle, secondary color (#62738d), checkmark icon |
| Pending (future step) | Outlined circle, secondary color, empty |

**Step Indicator Colors (Light):**
```css
.active-dot { background: #ff592c; transform: scale(1.2); }
.completed-dot { background: #62738d; }
.pending-dot { border: 2px solid #dce4eb; background: transparent; }
.progress-line-filled { background: #ff592c; }
.progress-line-empty { border: 2px dashed #dce4eb; }
```

### Dialog Styling

```typescript
// From src/components/ui/dialog.tsx
// Override for TutorialOverlay
DialogContent className additions:
- max-w-sm (w-full max-w-[320px])
- p-5 (body padding 20px)
- rounded-2xl (more rounded than default)
- shadow-neon (orange glow from globals.css)
```

**Dialog content override for tutorial:**
```css
.tutorial-dialog {
  max-width: 340px;
  padding: 20px;
  border-radius: 16px;
  box-shadow: 0 0 15px -3px #ff592c, 0 0 5px -2px #ff592c; /* shadow-neon */
}
```

### Animation

- **Dialog open:** Radix default `zoom-in-95 + fade-in-200`
- **Step transition:** framer-motion `AnimatePresence` with slide-left/right, 300ms
- **Step indicator active:** scale-110, 200ms spring
- **Button hover:** scale-105, 200ms (from globals.css `transition-all`)
